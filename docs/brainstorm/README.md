# Brainstorm

Freeform notes for ideas that aren't a spec yet — half-formed thoughts,
options being weighed, "what if we..." explorations. No required
structure. Name files whatever's clear, e.g. `2026-09-multi-tenant-idea.md`.

When an idea firms up enough to actually build, promote it to
`docs/specs/` as a proper spec and either delete the brainstorm file or
leave it as backstory.
